# ADR-003: Comunicación mediante API REST

**Estado:** Propuesto

## Contexto
El Sistema Básico de Control de Inventario para un Centro Naturista necesita que el empleado pueda registrar productos naturales, consultar existencias y actualizar cantidades mediante una interfaz web. La interfaz debe comunicarse con la lógica de negocio sin acceder directamente a la base de datos MySQL.

## Decisión arquitectónica
Se propone implementar una API REST que utilice el protocolo HTTP y el formato JSON para intercambiar información entre la interfaz web y el servidor.

La API ofrecerá operaciones para registrar productos, consultar el inventario y actualizar las cantidades disponibles.

## Atributo de calidad protegido
Interoperabilidad. La API REST permitirá que diferentes interfaces compatibles con HTTP y JSON puedan comunicarse con el sistema mediante un contrato definido.

## Alternativa considerada
Permitir que la interfaz se conecte directamente a MySQL para realizar consultas y actualizaciones.

## Justificación
La elección del mecanismo de comunicación es difícil de cambiar porque los clientes dependerán de las rutas, los métodos HTTP y los formatos de datos establecidos. Reemplazar posteriormente la API exigiría modificar las solicitudes, adaptar los componentes y repetir las pruebas de integración.

## Consecuencias
**Positivas:** separación entre cliente y servidor, comunicación estandarizada, mayor interoperabilidad y centralización de las validaciones.

**Negativas:** requiere mantener los endpoints, validar las solicitudes y gestionar los errores de comunicación.

## Escenario de calidad propuesto
Un cliente HTTP enviará una solicitud GET para consultar los productos. La API deberá responder con datos JSON válidos. Las solicitudes de actualización deberán validar las cantidades antes de modificar el inventario.

## Evidencia documental
Este ADR registra una decisión arquitectónica propuesta. Su aplicación deberá verificarse posteriormente mediante los endpoints implementados, ejemplos de solicitudes HTTP y pruebas de integración.
